# 🎨 Front-End Practice

> A 30-day challenge to learn front-end development by building small, real-world projects every day.

---

## 🤔 Why?

- 🛠️ Learning by **doing**, not just watching tutorials  
- ⚡ Building a **habit** of daily coding  
- 📁 Creating a **portfolio** step by step  

---

## 📂 How to use

Each day's project is in its own folder with an `index.html` file.  
Open it in any browser to see the result.
