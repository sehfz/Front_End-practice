# Day 02 - My Favorites List

A simple HTML page listing my favorite movies, books, and actors with links and images.

## What I learned / practiced:

- Ordered lists (`<ol>`) and unordered lists (`<ul>`)
- Nested lists (list inside a list)
- Links (`<a href="...">`) to external websites
- Text formatting: `<strong>` (bold) and `<em>` (italic)
- Horizontal rule (`<hr>`) for separation
- Images (`<img>`) with `width` attribute
- Basic page structure with `<head>` meta tags
