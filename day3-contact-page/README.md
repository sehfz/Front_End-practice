# Day 03 - Contact Page

A simple and clean HTML contact form.

## What I learned / practiced:

- Creating forms with `<form>` tag
- Different input types: `text`, `email`
- Connecting labels to inputs with `for` and `id`
- Multi-line text input with `<textarea>`
- Submit and reset buttons
- Using `placeholder` for input hints
