# Day 04 - Weekly Schedule

A simple weekly schedule table created with HTML.

## What I learned / practiced:

- Creating tables with `<table>`, `<thead>`, `<tbody>`
- Table rows `<tr>` and table cells `<th>` (header) / `<td>` (data)
- Adding border with `border="1"` attribute
- Basic inline CSS with `<style>` tag (`text-align: center`)
