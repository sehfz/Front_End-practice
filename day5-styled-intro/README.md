# Day 05 - Styled Introduction Page

A personal introduction page styled with CSS.

## What I learned / practiced:

- Adding CSS to HTML (Internal style)
- CSS selectors: element selector (`h1`, `p`, `ul`, etc.)
- Common CSS properties:
  - `background-color` for page background
  - `color` for text color
  - `font-family` and `font-size` for typography
  - `border`, `border-radius` for styling boxes
  - `padding` and `margin` for spacing
  - `text-align` and `display: block` + `margin: auto` for centering
- Styling lists and images
