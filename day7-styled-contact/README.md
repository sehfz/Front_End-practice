# Day 07 - Styled Contact Form

A beautifully styled contact form with focus and hover effects.

## What I learned / practiced:

- Styling forms with CSS
- **:focus** pseudo-class for input fields
- **:hover** effects on buttons
- **Gradient backgrounds** on page and button
- **Box-shadow** for depth
- **Transition** for smooth animations
- **Box-sizing: border-box** for accurate sizing
