# Day 08 - Login Page

A modern and clean login page with focus and hover effects.

## What I learned / practiced:

- Building a login form with HTML
- Styling form elements with CSS
- **:focus** pseudo-class for input fields
- **:hover** effects for buttons and links
- Making input fields and button the same width
- Styling links without default underline
- Using **gradient** backgrounds
